# Code Steward audit, round 1 (Oct 28, 2026)

Audit only. No code was changed. Branch `claude/uic-campus-game-plan-btnm3c` at `9c65098` (4 doc commits ahead of `origin/main` at `149944d`).

## Summary

The code is in better shape than its speed of growth suggests. `npm test` passes (84 files, 566 tests, 80 s wall clock), `npm run typecheck` is clean (5 s), the production build works, `npm audit --omit=dev` reports 0 vulnerabilities, and the pinned versions in `CLAUDE.md` match what is installed (three 0.186.1, Rapier 0.21.0, Vite 8.3.4, Vitest 5.0.3, TypeScript 7.0.2). The pure-logic layers (damage, zone, squad rules, steering) are well tested, and there are no empty tests.

The problems are at the edges:

1. **Debug and test hooks ship in the public build** (`window.__zone.skip()`, `window.__gfx`, `window.__player` via `?test`, `?gfxtest`, `?playertest`). This breaks the Code bar ("no debug leftovers in the public build"). Also, `?debug=perf` currently turns on all cheat keys.
2. **No LICENSE file**, although `CREDITS.md` says six building models are "released under the project license".
3. **The repo is heavy**: `.git` is 237 MB, and 168 MB of that history is screenshots. 148 MB of PNGs sit in the working tree.
4. **69 of 73 remote branches can be deleted** (66 fully merged, plus the three squash-merged `cursor/*` branches). The other four are `main`, the working branch, and two branches with open PRs (#72, #73) that merge cleanly.
5. **CI gaps**: the Pages deploy never runs tests or typecheck, CI runs twice per PR, and the Python tests never run.
6. **Docs have drifted**: `postprocessing` and `n8ao` are runtime dependencies that `CLAUDE.md` never mentions (it tells agents to use `three/addons/postprocessing`). Role names, viewpoint prefixes and the README's cheat-key rule are also out of date.
7. **Structure**: `main.ts` (280 lines) and `squad/adapter.ts` (1050 lines) carry too many jobs. Bot physics lives in `player/`. Ground-probe, muzzle-point, RNG and body-size code is duplicated.
8. **A small gameplay bug found by reading**: bots can never score a headshot on a crouched player (CODE-14).

What was not done: no dev server, no screenshots, no Playwright runs (shared machine). The Playtest and player-test tools were read, not run. Coverage was estimated from the import graph, because no coverage tool is installed. Dead-code detection used a regex script rather than `ts-prune`, so dynamic uses could be missed.

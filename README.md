# UIC Campus Game

A 3D, browser-based, multiplayer game set on the real University of Illinois Chicago campus.
Players take on missions across a campus built from real map data, such as getting to class on time or catching the Blue Line.

**Status:** Planning. See [`PLAN.md`](PLAN.md) for the full plan, team structure and roadmap.

> Unofficial fan project. Not affiliated with or endorsed by the University of Illinois Chicago.
